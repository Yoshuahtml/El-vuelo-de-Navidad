# El vuelo de la Navidad · COPPHU 2026

Sitio estático (HTML + CSS + JavaScript, GSAP y ScrollTrigger desde CDN).

## Abrir en VS Code
1. Instala la extensión **Live Server**, abre esta carpeta y pulsa "Go Live".
   (o en terminal: `python -m http.server 8000` y abre http://localhost:8000)
2. Necesita internet para cargar GSAP desde cdnjs.

## Archivos
- `index.html`: contenido y estructura de las escenas.
- `styles.css`: estilos y paleta oficial.
- `main.js`: menú, animaciones de scroll, música y descarga de la invitación (PNG).
- `assets/`: ilustraciones (WebP con transparencia) y `musica.mp3`.

## Notas
- La música solo suena al pulsar el botón. Revisa los derechos de la grabación antes de publicarla abierta.
- Para cambiar una ilustración, reemplaza el archivo en `assets/` (mismo nombre y proporción).
